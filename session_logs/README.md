# session_logs/

Put the full export of every AI session you used for this assignment in this folder, next to this file.

- One file per session; several files are expected if you used several sessions or tools.
- The raw export (.jsonl, .json) is best; a markdown export is fine. See "Exporting AI session logs" in CANDIDATE_BRIEF.md for export instructions.
- Include the conversation from the first prompt to the last. Do not edit or shorten it; remove only secrets, API keys and personal data.

A submission with no session log in this folder is not graded.
